🔹 2. pages/ → scripts por página

Esto es lo que más suele confundirse.

👉 Qué es

Cada archivo representa una “pantalla” de tu app (aunque uses un solo HTML).

login.js → pantalla de login

register.js → pantalla de registro

worker.js → panel del trabajador

👉 Qué hace cada archivo

Renderiza HTML

Escucha eventos (click, submit...)

Llama a la API

Actualiza la UI
